# 净屏 2.4.0：哪些广告会处理，规则如何验证

本版改进了哔哩哔哩普通版（`tv.danmaku.bili`）和其他播放器，并参考 [GKD v1.13.2](https://github.com/gkd-kit/gkd/tree/301e7e0a2aeb6ede954dcb93dbf53e56ae45a57d) 的规则执行、订阅管理和快照审查设计。选择器、应用识别和样本工具均在净屏代码中实现；[第三方规则与样本来源](../NOTICE.md)分开对待。

## 哔哩哔哩

- **开屏跳过**：识别底部原生跳过按钮和它所属的启动广告图层。适配首次启动、确认上一次已退出后紧接出现的启动层，以及从播放页返回首页时的广告。广告覆盖首页时不会点到后面的卡片。[旧样式](https://i.gkd.li/i/16187624) · [新版容器](https://i.gkd.li/i/16484445)
- **使用中广告**：支持评论区广告横幅的独立关闭键，以及播放器在“几秒后将展示广告”旁提供的「取消」。只有倒计时、广告提示、可点击的取消项在同一排时，才把取消当作广告出口；不会用普通播放器的取消、定位或弹幕开关代替。[评论页](https://i.gkd.li/i/12785461) · [播放器](https://i.gkd.li/i/29379312) · [同时含其他提示](https://i.gkd.li/i/32783449)
- **首页和播放器下方推广**：进入「使用中广告」可单独打开「允许用反馈收起哔哩哔哩广告」，默认关闭。净屏仅从已标明广告的卡片打开专用菜单，核对同页有广告说明，才会选择针对该条内容的反馈。会向哔哩哔哩提交反馈、可能影响推荐；不帮用户投诉、屏蔽作者，也不操作用户自己打开的反馈菜单。[首页广告](https://i.gkd.li/i/18274379) · [相应菜单](https://i.gkd.li/i/18274380) · [播放器下方](https://i.gkd.li/i/28658095)

## 其他应用

爱奇艺 PAD 的特定横屏暂停广告，目标是「关闭广告，放大暂停画面」的可点击父层。优酷的特定暂停广告，核对广告标识和关闭图标的原生外层按钮，避免误点静音或跳转详情。对于仅看到多个无文案、无独立身份的图片按钮的腾讯视频暂停样式，本版不推测坐标。[爱奇艺 PAD](https://i.gkd.li/i/23837894) · [优酷](https://i.gkd.li/i/14321469) · [腾讯视频边界样本](https://i.gkd.li/i/24689566)

## 与 GKD 对照，怎么理解结果

| 能力 | 本版净屏 |
|---|---|
| 按页面和控件匹配 | 可识别父子、祖先、兄弟、目标标记、节点序号/深度、文本或 ID 等属性；可导入必备、任选前置及排除条件。 |
| 规则调度 | 可导入适用的页面前缀、排除页面、启动延时、有效时间、优先时段、运行顺序和次数/冷却条件；延迟后重新核对窗口。无法表达的动作或约束会跳过。 |
| 管理和恢复 | 支持本地文件、粘贴及完整版 HTTPS 来源。逐条启停、差异预览、恢复上版；完整版可按来源启用每天前台检查，有新版本仍由用户审阅。 |
| 样本与诊断 | 可导入净屏 JSON 或 GKD 快照的 JSON/ZIP。只使用本地精简节点，不显示原快照截图或保留个人正文。正例与普通页共用同一表达式进行回放，外部输入控件页面不导入。用户可选择把样本保存在本机库，批量清除。 |
| 本地记录 | 只在用户开启「保留开屏与弹窗明细」时累积按应用的确认次数、最近尝试时间；关闭明细时清除。 |
| 权限与跨端 | 净屏使用公开无障碍接口、用户可见的系统安装器和本地桌面样本审查器；未提供 GKD 的特权服务、跨设备远程控制或 Windows 客户端。 |

**实际导入大型订阅。** 直接使用未修改的 AIsouler v406 和 Lin-arm v644 文件，分别经过预览、保存、重新加载和实际启用检查：前者接入 58 条、覆盖 55 个应用；后者接入 73 条、覆盖 69 个应用。这不是两份订阅的全部规则。遇到不能完整保留的共享限制、动作或表达式，不会删掉条件后强行执行。两份来源的 B 站开屏规则均保留完整窗口查询、优先期、顺序、冷却、最大次数和按应用重置。

**比较的是同一棵树上的目标，不是两款应用的真实广告消失率。** 此轮 B 站样本来自 74 棵不同的真实页面树，另比对 20 份跨平台页面。使用 GKD 官方选择器和固定版本 Lin-arm v644、AIsouler v406 社区订阅比较。GKD 本体默认不附带这些规则。Lin-arm v644 在三份 B 站播放器样本里选中的「取消」和净屏一致；在另两份腾讯倒计时/权益样本上，选择器能返回尚未解锁的文字，而净屏不选。没有同一台手机、同一投放下的双应用关闭与耗电结果，因此不宣称总胜率、总覆盖或速度超过 GKD。
