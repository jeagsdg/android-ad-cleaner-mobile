## 签名、样本与回滚

`RulePack.verify` 先验固定证书指纹和 RSA 签名，再检查客户端范围、字段白名单、受保护页面、独立广告标识、关闭控件与规则编号。`schema=2` 对两份内置文件的 UTF-8 原始字节分别取 SHA-256，签名正文内引用有序索引；基底、场景、编号重复或版本错误即拒绝。旧版全量包由原 URL 提供。纯离线版继续支持从本地文件或粘贴管理社区订阅，没有远程下载入口。

以修改前 408 条均不变的目录作可重复尺寸比较，同一组元数据的完整签名正文为 315,764 字节，增量正文为 1,777 字节。数值不含证书、Base64 和 HTTP 开销。3.0.0 候选的 v6 增量适配 code 27；实际完整签名文件 4,291 字节，正文 1,781 字节。独立验签并复算两份目录哈希，确认 157 条开屏和 252 条应用内规则按原序引用。增量兼容测试使用独立测试证书，产品固定指纹拒绝该夹具。新增的外部分发规则在构包工具中需要逐条给出同包正负样本，使用客户端解析器和选择器离线回放。未提交第三方真实样本的规则无法据此获得真实设备验证等级。

## 复查后补充的保护

手动收藏的旧样本保留至用户删除。新增可选保存 7 天或 30 天，到期后下次访问库时清理。保存时在同一把锁内复核 64 份和 32 MiB 总配额，达到任一限额便拒绝新写入；列表只读文件头。JSON5 层级检查也覆盖导入的普通 JSON 或 ZIP 中的页面；缺失子树会把本次回放标为不完整。已遮蔽的正文不能被当作已知空文字。单个不可读的订阅记录只影响该来源。官方预览中的修改项会显示变化字段和新旧值。

## DNS 与系统清理

网络版只为本机 DNS 地址建立 VPN 路由。应用绕过由 Android 的 `addDisallowedApplication` 设置，运行中会在同一服务内建立替代接口，成功后才关闭旧接口并保存名单。此前的请求只允许写回其原接口。系统拒绝新配置会保留旧配置并显示原因；用户停用或撤销授权后不会自动重新启动。撤权时服务退出，查询使用原物理网络，上游有超时并在连续失败后退出。Android 9 的私人 DNS 另有保护。用户可停用过滤、放行完整域名和移除自定义拦截。应用自行使用 DoH、直连 IP 或同域发布内容和广告时，域名过滤不能可靠区分。本轮没有新的真实运营商网络、厂商 VPN 冲突或端到端延迟数据。 [Android VPN 路由和按应用排除](https://developer.android.com/reference/android/net/VpnService.Builder)

系统推广清理的普通入口经 `CleanerService.runPreview` 读取，再由 `applyPreview` 确认用户选择的条目。执行前复核页面、路径、版本、观察标签和目标状态，写入前保存原值，操作后回读。恢复走选中变更记录的 `restoreEntry`。既有 `CleanRetryTest` 涵盖 6 项 JVM 回归，本轮未在用户真实手机上修改厂商设置。

## 验证边界

修改前采用单独源码副本，8 个测试类共 41 项通过。规则与辅助模块第一轮定向回归 11 个测试类共 54 项通过，含独立工作目录中的完整订阅回放。最终复查扩大至 15 个测试类，109 项全部通过，涵盖旧格式、隐私、新增收藏配额、到期清理、单源损坏隔离、更新字段预览和官方 v6。使用 Android API 28 Robolectric、分离的本地工程和完整订阅输入运行回归；输入包括有独立来源的原订阅文件，以及专为保护边界构造的测试页面。依赖实际系统 VPN、用户选定的 AI 服务、系统厂商设置和两份被人工正确标注的页面样本的场景，无法从单元测试推导真实成功率。
