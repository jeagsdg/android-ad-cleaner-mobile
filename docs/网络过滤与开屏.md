# 网络过滤与开屏跳过

开屏跳过和应用内弹窗在两个版本中都可独立开启。网络过滤由完整版提供，首次开启时需要确认 Android 的 VPN 请求。纯离线版无 Android 联网权限，系统中不会注册净屏的 VPN 服务。

## 开屏与弹窗

净屏在应用切到前台后识别开屏广告的「跳过」控件。候选会核对应用、窗口、可见性以及规则需要的广告标识或控件关系。点击后重新读取页面，确认目标消失才计入成功。可在「管理开屏跳过」设置应用排除、成功标记和前台保活。

应用内广告弹窗有独立开关。你可以按应用启停内置规则，也可以编辑自己的规则，限定应用、页面、目标控件和等待时间。连续步骤在前一步确认后推进。

0.9.0 的开屏和弹窗专属候选合计覆盖 **195 个不同包名**，其中开屏 **101 个**、弹窗 **111 个**。部分应用同时有两种候选。广告布局变化、不可读的自绘控件及较晚出现的开屏广告都可能影响处理结果。视频内嵌广告另属播放场景。 [应用覆盖](应用覆盖.md) · [验收记录](../artifacts/验收记录-v09.md)

## 本机 DNS 过滤

净屏通过 Android VPN 接收发往本机过滤接口的 DNS 查询，以内置规则匹配完整域名。未拦截的查询仍由当前网络的 DNS 处理，普通应用流量走原有网络。设备只能同时使用一个 VPN。Android 9 启用私有 DNS 时，净屏会保留现有设置并提示暂无法叠加过滤。

过滤内置 **235,866 个域名**。你可以手动添加放行域名，也可以先开启「保留最近拦截域名」，再从最近拦截中逐项放行。查询可能受 DNS 缓存影响。拦截次数统计的是 DNS 请求，实际看到的广告数由应用内容决定。 [域名数据来源](../NOTICE.md)

应用自带的加密 DNS、硬编码 IP、已缓存内容、与正常内容共用域名的广告，以及视频内嵌广告可能继续显示。网络过滤会在无法稳定解析时退出，让系统接管后续查询。

## 数据设置

在「使用说明」可以分别开启开屏与弹窗明细、最近拦截域名，或针对一个应用启动五分钟开屏诊断。明细保存在手机上，关闭后清除既有明细。诊断结果由你预览和复制。完成系统设置操作后，恢复所需的原值会保留在本机。
