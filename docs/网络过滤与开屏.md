# 网络过滤与开屏跳过

0.3.0-preview 新增两项独立功能，不替代系统设置清理。默认关闭，用户分别确认后开启。当前是供兼容性测试的预览版本。

## 网络过滤

使用 Android `VpnService` 建立本机 DNS 过滤接口。只有 `198.18.0.2/32` 的 DNS 目的地址进入接口，普通应用流量由原网络传输。支持 UDP 和 TCP DNS；不会建立远程 VPN 通道、解密 HTTPS、安装证书或读取 HTTP 内容。VPN 一次只能由一个应用占用，因此与其他 VPN 互斥。

规则来自 Block List Project 的 ads.txt，固定提交 `ee3bdbaddf49c756cf3340bb2e6a9dee5282d1c6`，Unlicense。经语法校验、排序、去重及明确的联网检测域名保护后，内置 **235,866** 个完整域名。`tools/import_dns.py` 核验上游 SHA-256 后确定性生成压缩资产；来源、源文件哈希与规范化哈希在 `app/src/main/assets/dns-source.json`。规则不在后台联网更新。数量不代表实机拦截效果。

只匹配完整域名，不把一条 hosts 规则扩展成全部子域名。用户可查看最近 30 个被拦域名，逐项放行或手动添加完整域名。放行即时影响后续查询，但 Android 或应用已有缓存可能需要等待、重开应用后才体现。

Android 10 起使用系统 `DnsResolver.rawQuery`，明确指定物理网络，由系统处理上游与加密 DNS。Android 8/9 使用当前网络公布的 DNS 服务器，并保护、绑定上游 socket；UDP 截断时转 TCP。Android 9 检测到私有 DNS 已启用时拒绝叠加过滤，保留原设置；不会为了拦广告静默改用公共 DNS。

请求队列、TCP 连接数、单包长度、重传次数和记录数量有界。连续解析失败、接口错误或网络断开时退出 VPN，让系统恢复原网络解析。没有启用 always-on，也不声称后台被厂商结束后仍在保护。开关状态依据当前服务与 TUN，不用上次保存的“开启”冒充正在运行。

局限：应用自行发送到其他服务器的 DNS、私有 DoH、硬编码 IP、缓存广告、同域名广告与内容，以及视频内嵌广告可能绕过本过滤。系统严格私有 DNS 与 OEM VPN 的组合也需要实机验证。统计是 **拦截的 DNS 请求数**，不是清掉的广告条数。

## 开屏跳过

用户开启后，无障碍服务在应用切到前台的 12 秒内尝试识别广告控件。泛化规则要求明确广告标识和位于边角的小型“跳过”控件；明确的“跳过广告 / Skip Ad”也可作为依据。支持部分中文、繁体与英文倒计时形式。最多沿两层父节点寻找唯一可点击控件；不使用盲点坐标、不点任意 X / 关闭，不处理可见输入框、权限同意或已识别奖励广告页面。

0.8 内置 68 条应用专属候选（58 个应用），另有 3 类明确的 SDK 开屏规则。依据包括 MIT 的 ganlinte/GKD-subscription v72 和已核对的安装包。生成工具按固定源文件校验哈希，将精确资源名、受限节点关系及页面条件转成可核对的谓词。选择目标时还需满足可见、唯一、安全及窗口位置要求。原文和许可证在 vendor/gkd-splash-reference，生成工具为 tools/import_splash.py。第三方应用当前版本的命中率需要单独验证。

每次前台切换最多尝试一次。点击后检查同一应用内目标控件是否消失；无法确认就不计入确认次数，不反复点击。用户点击、输入、锁屏、权限页、设置清理任务期间会停止当前识别窗口。应用排除列表用于跳过容易误匹配或无需处理的应用。

无法读取的图片/自绘控件、复杂布局或过晚出现的广告会保留。这是有边界的自动操作，不是“任何广告都能跳”。无障碍被系统拒绝时，开屏跳过与设置清理不可用，网络过滤仍可独立授权。

应用内弹窗有独立开关。0.5 新增通用广告弹窗识别，在同一紧凑面板内匹配广告标识和明确的关闭广告按钮，并保护隐私提示和奖励广告。兼容规则可匹配可见控件的精确范围，或对已识别的独立弹窗执行返回。联合规则依次核对条件，只有已确认关闭才推进点击步骤。用户界面的备份和还原使用净屏格式。

## 权限与隐私

- INTERNET / ACCESS_NETWORK_STATE：向当前物理网络解析 DNS，跟踪网络切换。
- FOREGROUND_SERVICE / FOREGROUND_SERVICE_SYSTEM_EXEMPTED：运行用户已授权的 VPN。旧 AGP 8.5 的 Lint 未识别“已配置 VPN”例外，局部忽略此服务的 `ForegroundServicePermission`，不通过添加无关闹钟权限消除警告。实际启动必须经过系统 VPN 授权并测试。
- FOREGROUND_SERVICE_SPECIAL_USE：用户单独开启跳过保活时，使用前台服务显示可停止的通知，系统负责无障碍连接。
- POST_NOTIFICATIONS：展示过滤与跳过保活的状态和停止入口。VPN 授权与通知访问分别管理。
- 无障碍：仅在用户开启相应功能后用于控件识别/点击。不开启时不执行开屏处理。

不保存截图、输入内容或页面正文。被拦域名仅保存在应用私有目录，诊断不导出域名历史或放行列表。网络计数、本机状态可进入诊断。没有自有服务器、账号或第三方广告/统计 SDK。
