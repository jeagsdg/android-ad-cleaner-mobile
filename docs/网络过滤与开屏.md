# 网络过滤与开屏跳过

开屏跳过和应用内弹窗在两个版本中都可独立开启。网络过滤由完整版提供，首次开启时需要确认 Android 的 VPN 请求。纯离线版无 Android 联网权限，系统中不会注册净屏的 VPN 服务。

## 选择处理场景

首次点首页「开启自动跳过」，可选「同时开启」或「只跳开屏」，也可以取消。已有设置按上次选择保留。首页显示服务是否真的连接；系统开着但净屏还没连接时，暂时无法跳过广告。在「使用中广告」里管理刷视频、看短剧、浏览信息流时出现的广告。应用排除项和单条规则仍由你控制。

**微信小程序。** 净屏只尝试识别广告自身的跳过控件。已适配带广告标记的左上胶囊，以及部分网页广告中位于小程序胶囊下方的倒计时跳过文字。右上角用于退出小程序的「关闭」不会作为替代目标。

**腾讯视频。** 开屏广告使用「开屏广告跳过」。播放中还需要开启「使用中广告」；当普通的「跳过广告」与「VIP可关闭该广告」同时出现时，只选择实际可用的普通入口。未解锁、奖励页、无法读取的广告不按可关闭处理。

**虎牙和斗鱼。** 进应用时的广告由「开屏广告跳过」处理；直播中途出现的商单要开启「使用中广告」。只会尝试已识别的广告退出入口。普通直播画面的退出按钮、打赏和会员入口不是广告关闭键。

**需要先打开广告菜单时。** 在已适配的样式上，净屏会先核对广告标记和专用关闭图标，再打开菜单并核对真正的退出项。菜单不匹配就停，打开菜单不算成功。部分微博页面只提供「不感兴趣」；在「使用中广告」里另行开启后，净屏才会在对应的广告菜单提交此反馈，可能影响微博推荐。此选项默认关闭，不会选择举报或屏蔽博主。

**广告长达 15 秒怎么办？** 已经能关闭就尽早点。只有“几秒后可跳过”的提示时，不会把提示当按钮。红果已适配的竖屏广告，在出现“上滑继续观看短剧”后尝试应用自身的翻页动作。同一应用里连续出现的通用弹窗只在确认前一次关闭后继续处理。

**刚才没跳过。** 首页入口会优先打开服务近期观察到的可启动应用，也可换选；服务不运行或没有近期应用时手选。不要求留存浏览历史。先检查服务连接、开关和排除项；有本地证据才显示最近一次的结果，否则可重现一次。进一步排查可以自愿采集脱敏样本或试运行规则。[应用覆盖](应用覆盖.md) · [样本工具说明](规则工具对照.md)

## 本机 DNS 过滤

净屏通过 Android VPN 接收发往本机过滤接口的 DNS 查询，以内置规则匹配完整域名。未拦截的查询仍由当前网络的 DNS 处理，普通应用流量走原有网络。设备只能同时使用一个 VPN。Android 9 启用私有 DNS 时，净屏会保留现有设置并提示暂无法叠加过滤。

过滤内置 **235,866 个域名**。可手动添加完整域名作为拦截或放行项，也可以先开启「保留最近拦截域名」，再从最近拦截中逐项放行。查询可能受 DNS 缓存影响。过滤运行中保存应用绕过名单后，净屏会使用现有 VPN 授权切换接口。切换成功后指定应用使用系统原网络；系统拒绝建立替代接口时，继续用旧名单，并提示原因。停止状态下保存的名单在下次开启时生效。拦截次数统计的是 DNS 请求。 [域名数据来源](../NOTICE.md)

应用自带的加密 DNS、硬编码 IP、已缓存内容、与正常内容共用域名的广告，以及视频内嵌广告可能继续显示。网络过滤会在无法稳定解析时退出，让系统接管后续查询。

## 数据设置

在「使用说明」可以分别开启开屏与弹窗明细和最近拦截域名。关闭明细后会清除已有记录。首页的「刚才没跳过」可从净屏刚刚识别的前台应用开始诊断，也可从「应用广告管理 → 刚才没跳过」指定应用。重现广告并预览规则命中状态和控件信息后，可选择复制或保存。记录省去原始控件文字和截图，也不会自动上传。完成系统设置操作后，恢复所需的原值会保留在本机。
