# 机型适配

净屏可安装在 Android 7.0 及以上版本。开屏跳过、弹窗处理和完整版的网络过滤使用 Android 提供的接口。营销通知渠道清理需要 Android 8.0 及以上。系统授权入口、后台限制和第三方应用可读取的控件仍因厂商、系统和应用版本而异。 [授权帮助](权限兼容.md)

## 查看本机能尝试什么

- 「使用说明 → 本机适配」显示设备识别信息与可尝试的规则。
- 「系统广告设置」展示已识别的本机候选。小米 / Redmi / POCO、OPPO / 一加 / realme、vivo / iQOO、荣耀和魅族等系统家族的部分推广设置有专属候选。实际项目取决于已安装的系统应用与可读取的页面。
- 三星、华为的 Android 兼容系统和其他机型可使用系统授权、隐私和通知设置入口。Android 13 及以上的净屏子页接入系统返回手势。 [Android 返回手势](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)
- 如果锁屏或切换应用后服务经常断开，可在「管理开屏跳过 → 前台保活 → 检查后台限制」查看本机相关设置。

系统推广清理只处理可识别的目标。「清理结果」会显示已核验、已是目标状态、尚未执行和需要核对的项目。中断后可以续跑或选择单项重试。净屏会保存可恢复改动的原值，供「改动记录与恢复」使用。

第三方应用规则和系统设置路径分别维护，专属规则数量反映候选范围。 [应用覆盖](应用覆盖.md) · [1.0.0 验收](../artifacts/验收记录-v10.md) · [规则来源](../NOTICE.md)
