# 授权帮助

## 开启无障碍服务

在净屏首页开启需要的功能，按引导进入系统无障碍设置，选择「净屏」并确认。不同系统可能把服务放在「已下载的应用」或「已安装的服务」下。授权后返回净屏，等待页面显示服务已连接。

如果系统开关已开启、服务尚未连接，可重新打开净屏的授权页检查状态，并查看系统是否限制净屏后台运行。入口在「管理开屏跳过 → 前台保活 → 检查后台限制」。

## 小米无障碍连接守护

在小米、Redmi 或 POCO 手机上开启开屏跳过或弹窗处理，然后在首页点「无障碍连接守护」。在系统设置开启净屏无障碍、允许守护通知，返回后点「开启连接守护」。升级前曾开启自动恢复的用户，也可以到这里确认守护是否正在运行。

- **开关已开启，服务未连接。** 净屏等待 Android 重新绑定服务。守护先在约五分钟内复查六次，之后每十五分钟复查一次。手机睡眠时复查可延后，亮屏、解锁、返回净屏或系统开关变化时会再检查。仍未恢复时，可从守护页进入无障碍设置检查「净屏」。
- **无障碍开关已关闭。** 守护检测到后会发一条提醒并结束本次守护；点提醒进入系统设置。需要继续使用时，打开「净屏」开关，回到首页确认服务已连接，再按需开启守护。
- **停止连接守护。** 若常驻保活随本次守护一并开启，停止守护也会结束该通知。此前单独开启过「前台保活」时，停止守护会恢复原来的保活设置。通知中的「停止保活」可以一起关闭两项。
- **后台运行经常中断。** Android 若重新启动当前守护，净屏会继续检查。在 Android 11 及以上，如果系统记录能确认同次开机中因资源回收中断，返回净屏时也可接续。主动停止或手机重启后，按需手动开启。可点「检查后台限制」进入应用详情，核对小米的「省电策略」和「后台自启动」。具体位置取决于机型。 [小米后台自启动说明](https://www.mi.com/uk/support/faq/details/KA-507608/)

2.1.0 通过系统提供的无障碍设置管理授权，省去了 2.0.1 的开发者选项、无线调试和 USB 授权步骤。首页「刚才没跳过」可查看最近五分钟内记录到的断连，也可以选择一个应用重现广告。

## 系统提示「受限制的设置」

Android 13 及以后，某些安装来源下系统会限制无障碍和通知访问。如果你信任下载的安装包，并且系统提供允许选项，可以打开「设置 → 应用 → 净屏 → 应用信息」，在右上角菜单选择「允许受限制的设置」，再返回系统无障碍设置。菜单名称和位置随系统而异。 [Android 官方帮助](https://support.google.com/android/answer/12623953?hl=zh-Hans)

部分 ColorOS 版本在「应用详情 → 权限管理 → 右上角 ⋮」提供解除限制的选项。部分小米系统把相关选项放在应用详情的「高级设置」中。以当前设备实际显示的提示和可用菜单为准。缺少入口或设备受管理策略限制时，开屏、弹窗和设置自动操作会等到系统授权可用后才运行。

## 可选授权

| 功能 | 系统授权 |
| --- | --- |
| 完整版的网络过滤 | 首次开启时确认 VPN 请求 |
| 营销通知渠道检查（Android 8.0 及以上） | 在系统「通知使用权」或「通知访问权限」中开启净屏 |
| 前台保活与状态提醒 | 在系统通知设置中允许净屏显示通知 |

这些功能可以分别配置。系统页面入口因机型而异，兼容范围见 [机型适配](机型适配.md)。

## 最近任务中的净屏卡片

打开「净屏 → 使用说明 → 在最近任务中隐藏」。这只改变 Android 最近任务中净屏自己的卡片，不会隐藏桌面图标，也不会授予权限或延长后台寿命。要恢复，请从桌面启动净屏，在相同位置关闭开关。已安装用户升级时默认保持原有任务展示行为。
