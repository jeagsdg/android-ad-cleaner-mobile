# 授权兼容与系统限制

净屏 0.3.0 将授权流程按所有支持的 Android 设备设计，最低 Android 8.0（API 26）。**通用流程不等于所有版本都已实测，也不等于 App 可以自行解除系统限制。** OPPO Find X8 Pro / ColorOS 16.0 已收到用户提供的系统拒绝与帮助页面截图；尚未连接该设备验证修复效果。

## ColorOS 16 的实际卡点

用户截图明确：系统帮助要求进入 **应用详情 → 权限管理 → 右上角 ⋮ → 解除所有授权限制**，菜单不在应用详情首页。旧版 0.2.0 没有普通运行时权限请求，页面显示“未请求任何权限”，权限管理灰显，无法完成该路线。用户已经尝试覆盖安装但无效，不再将反复重装作为解决承诺。

净屏为网络过滤的运行状态通知声明 POST_NOTIFICATIONS。0.8 在适用的 ColorOS 系统上提供单独的「允许过滤状态通知」入口，处理通知请求后返回净屏。再点「重新检查权限管理」，打开净屏的系统应用详情。普通网络页管理通知会打开系统通知设置。**通知请求能否使 ColorOS 入口可用仍待该机实测。** 无障碍授权通过系统设置确认。ColorOS 的帮助还提示解除限制操作不可撤销。

若仍不能开启，不应卸载丢失恢复账本或关闭整机安全防护。可先用独立的本地 VPN 网络过滤；它仍需系统确认 VPN，不能替代开屏点击和设置操作。

## 已实现的通用处理

- 区分「未开启」「系统开关已开、服务未连接」「服务已连接」「无法读取状态」。只检查净屏自己的完整服务标识，不把其他无障碍服务开启当成净屏授权成功。
- 返回 App 后立即检查，页面停留期间检查连接变化。连接后显示可继续操作，**不自动发起清理**；退出前台后停止轮询。
- 尝试系统的服务详情入口；系统拒绝或不提供时，自动回退到公开的无障碍列表，再回退到设置首页。列表定位提示仅在系统支持时有效，不强行调用私有页面。
- 应用详情只打开净屏自身。跳转被拒或不存在时给出手动入口，不闪退，不误报授权成功。
- 可选的通知访问入口被厂商拒绝或缺失时，保留明确的提示框，给出系统搜索名称和权限帮助入口，不因跳转失败退出 App。
- 受限帮助按实际提示使用。ColorOS 16 按用户提供的官方系统帮助定位到权限管理内部菜单；小米系列说明部分版本位于高级设置；其他品牌保留通用说明，不编造未经验证的私有菜单。
- 可以通过系统文件选择器保存当前单 APK 安装包，保留原始签名和字节，方便用户用自带文件管理覆盖安装。无需卸载，不请求存储权限或安装权限，不自动安装，不修改安装来源记录。若未来变成分包安装，会拒绝只导出 base APK。
- 诊断增加净屏服务状态、服务标识和系统返回的安装器包名；来源缺失时为 `null`。**安装器包名不是信任结论，权限未开不是受限结论。** 限制原因记为 `not_determined`，需结合系统实际提示核对。

## 版本与厂商边界

| 范围 | 本版处理 | 验证边界 |
|---|---|---|
| Android 8–12L | 公共设置入口、只读服务状态、无入口时回退；安装器信息使用旧接口 | API 28 自动化覆盖；其他版本完整设备流程待验证 |
| Android 13 及以后 | 同一授权流程，增加受限设置说明；不尝试自动放行限制 | API 34 自动化与 AOSP 模拟器；更高版本/OEM 待验证 |
| OPPO / 一加 / realme | 通用逻辑 + 无解除入口的条件说明 | 对应系统版本需要实机核对，不能保证覆盖安装有效 |
| 小米 / Redmi / POCO | 通用逻辑 + 高级设置入口提示 | 菜单位置由具体系统版本决定 |
| 荣耀、vivo / iQOO、三星、Google、魅族和其他品牌 | 通用逻辑，不限制机型白名单 | 不能据通用逻辑宣称全部机型已通过 |

授权页不读取其他 App 的界面，因此不能在没有无障碍权限时识别系统弹窗，更不能自动点确认。系统明确拒绝、设备管理策略限制、安装器来源限制、服务断连是不同问题，不能用一条「解锁成功」混为一谈。

## 面向普通用户的后续工作

优先核对真实系统提示、诊断中的构建标识及安装来源，按实机证据维护引导。准备正式分发时，应评估厂商认可的正规应用分发渠道；渠道审核、系统信任和无障碍授权各自独立，不能承诺上架后一定无阻碍。

需要开发者选项、ADB、Root 或其他提权工具的路线会增加首次配置负担，本版没有加入。也没有将净屏错误声明为以帮助残障人士为主要用途的无障碍工具。

## 技术依据

- [Android 官方：受限制的设置](https://support.google.com/android/answer/12623953?hl=zh-Hans)：标准授权步骤和信任确认。厂商界面可能不同。
- [Android 官方：AccessibilityService 生命周期](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)：服务由用户开启、系统绑定；普通 App 不能自行启动授权流程的最终结果。
- [AOSP Android 14 权限声明](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android14-release/core/res/AndroidManifest.xml)：`OPEN_ACCESSIBILITY_DETAILS_SETTINGS` 为 `signature|installer`，不是普通应用可申请的运行时权限。
- [GKD 开发者 FAQ](https://gkd.li/guide/faq)：记录了 ColorOS 无解除入口和小米高级设置等差异。自带文件管理覆盖安装是可尝试的经验方案，**不是净屏已完成的跨厂商验证**。
