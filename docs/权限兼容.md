# 授权帮助

## 开启无障碍服务

在净屏首页开启需要的功能，按引导进入系统无障碍设置，选择「净屏」并确认。不同系统可能把服务放在「已下载的应用」或「已安装的服务」下。授权后返回净屏，等待页面显示服务已连接。

如果系统开关已开启、服务尚未连接，可重新打开净屏的授权页检查状态，并查看系统是否限制净屏后台运行。入口在「管理开屏跳过 → 前台保活 → 检查后台限制」。

## 小米无障碍自动恢复

1. 在小米、Redmi 或 POCO 手机上打开净屏，点首页「无障碍掉线？自动恢复」。页面会带你连接无障碍和允许保活通知。
2. 在手机「设置 → 关于手机」连续点按系统版本，开启开发者选项。在净屏选择用手机或用电脑授权。 [小米开发者选项说明](https://www.mi.com/global/support/faq/details/KA-168765/)
3. Android 11 及以上可选「用手机授权」。连接 Wi-Fi，在开源工具 aShell You 中选择配对本机，然后在开发者选项打开「无线调试」。用工具的通知输入系统显示的 6 位配对码，配对后在无线调试终端执行净屏页面提供的命令。 [aShell You 下载](https://f-droid.org/packages/in.hridayan.ashell/) · [本机配对图解](https://github.com/DP-Hridayan/aShellYou/wiki/Wireless-Debugging-Setup#own-device-as-target)
4. 用电脑授权时，在开发者选项开启「USB 调试」，用数据线连接自己的电脑，并在手机上确认。Windows 可把净屏 USB 授权助手放入 Google 平台工具解压目录，双击并确认。也可在电脑终端运行净屏页面提供的 USB 授权命令。 [Google 平台工具](https://developer.android.com/tools/releases/platform-tools) · [Windows USB 授权助手](../tools/ClearScreen-USB-Setup.cmd?raw=true)
5. 回到净屏，看到「已准备好」后点「开启自动恢复」。授权成功后可以关闭调试。如果设备没有无线调试入口，可以使用电脑。小米固件可能限制授权或服务恢复。若手机显示权限不足，检查开发者选项是否有「USB 调试（安全设置）」。

保活通知运行时，净屏约每 30 秒检查一次自己的无障碍开关。需要手动关闭无障碍时，先点「停止自动恢复」或从通知停止保活。手机重启或净屏进程退出后，需要在净屏里再次开启自动恢复。

## 系统提示「受限制的设置」

Android 13 及以后，某些安装来源下系统会限制无障碍和通知访问。如果你信任下载的安装包，并且系统提供允许选项，可以打开「设置 → 应用 → 净屏 → 应用信息」，在右上角菜单选择「允许受限制的设置」，再返回系统无障碍设置。菜单名称和位置随系统而异。 [Android 官方帮助](https://support.google.com/android/answer/12623953?hl=zh-Hans)

部分 ColorOS 版本在「应用详情 → 权限管理 → 右上角 ⋮」提供解除限制的选项。部分小米系统把相关选项放在应用详情的「高级设置」中。以当前设备实际显示的提示和可用菜单为准。缺少入口或设备受管理策略限制时，开屏、弹窗和设置自动操作会等到系统授权可用后才运行。

## 可选授权

| 功能 | 系统授权 |
| --- | --- |
| 完整版的网络过滤 | 首次开启时确认 VPN 请求 |
| 营销通知渠道检查（Android 8.0 及以上） | 在系统「通知使用权」或「通知访问权限」中开启净屏 |
| 前台保活与状态提醒 | 在系统通知设置中允许净屏显示通知 |

这些功能可以分别配置。系统页面入口因机型而异，兼容范围见 [机型适配](机型适配.md)。
