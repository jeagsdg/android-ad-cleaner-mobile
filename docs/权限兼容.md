# 授权帮助

## 开启无障碍服务

在净屏首页开启需要的功能，按引导进入系统无障碍设置，选择「净屏」并确认。不同系统可能把服务放在「已下载的应用」或「已安装的服务」下。授权后返回净屏，等待页面显示服务已连接。

如果系统开关已开启、服务尚未连接，可重新打开净屏的授权页检查状态，并查看系统是否限制净屏后台运行。入口在「管理开屏跳过 → 前台保活 → 检查后台限制」。

## 系统提示「受限制的设置」

Android 13 及以后，某些安装来源下系统会限制无障碍和通知访问。如果你信任下载的安装包，并且系统提供允许选项，可以打开「设置 → 应用 → 净屏 → 应用信息」，在右上角菜单选择「允许受限制的设置」，再返回系统无障碍设置。菜单名称和位置随系统而异。 [Android 官方帮助](https://support.google.com/android/answer/12623953?hl=zh-Hans)

部分 ColorOS 版本在「应用详情 → 权限管理 → 右上角 ⋮」提供解除限制的选项。部分小米系统把相关选项放在应用详情的「高级设置」中。以当前设备实际显示的提示和可用菜单为准。缺少入口或设备受管理策略限制时，开屏、弹窗和设置自动操作会等到系统授权可用后才运行。

## 可选授权

| 功能 | 系统授权 |
| --- | --- |
| 完整版的网络过滤 | 首次开启时确认 VPN 请求 |
| 营销通知渠道检查 | 在系统「通知使用权」或「通知访问权限」中开启净屏 |
| 前台保活与状态提醒 | 在系统通知设置中允许净屏显示通知 |

这些功能可以分别配置。系统页面入口因机型而异，兼容范围见 [机型适配](机型适配.md)。
