# 功能验收矩阵

表中“离线”指不声明联网权限的安装包。“设备”栏只计能够观察到结果的设备操作。JVM 测试中的 Android 环境和静态快照回放单列；同一棵树被不同通道选中不代表完成了一次关闭。

| 模块 | 用户操作与可观察结果 | 故障 / 恢复检查 | 离线版 | 已有证据与边界 |
| --- | --- | --- | --- | --- |
| 首次授权、首页与自检 | 选开屏或两类广告，授权后查看连接状态，运行“测试本机点击” | 取消授权保留原选择；手动按测试键不能显示自动测试成功 | 本地可用 | AndroidCompatibilityTest、PermissionAccessTest、ScreenTest；Android 15 实际服务驱动本地按钮 |
| 开屏与弹窗 | 开启场景后匹配出口，再核对界面变化；按包排除 / 暂停 | 搜索、文本输入、确认授权、普通关闭与用户切应用须拒绝旧动作 | 本地可用 | SplashSkipperTest、PopupAdRulesTest，设备套件 splash / popup-generic；261 个包另有逐包证据矩阵 |
| 长倒计时与播放器 | 延迟出口出现后才尝试关闭；红果、视频播放页和独立第二阶段分别核对 | 锁定倒计时、自然结束、权益控件、回到其他应用均有保护 | 本地可用 | TimedAdTest、ShortDramaAdTest、PlayerAdTest、MediaAssistTest；设备套件 countdown-ad。红果真实 15 秒全程缺样本 |
| 微博、哔哩哔哩信息流 | 显式启用后可从广告自己的菜单收起对应广告 | 用户打开的菜单、普通内容和未开启的反馈路径均需保持 | 本地可用 | WeiboMenuEvidenceTest、BilibiliEventEvidenceTest 实树与事件序列；第三方推荐结果不可离线核验 |
| 应用管理、规则与简单录入 | 查看应用覆盖、调整排除项和单条规则，录入后核对范围并保存 | 导入部分失败保留旧配置；普通文件/会员/支付操作必须被保护 | 本地可用 | CustomSkipTest、LegacySkipImportTest、ScreenTest；新录入入口以最后冻结版的操作记录为准 |
| 精选规则、订阅与 GKD | 预览差异、逐条启停、验证签名后生效，恢复并重启检查 | 摘要、版本、前置约束或签名不符时拒绝；原用户禁用项保留 | 本地导入和恢复，在线订阅仅完整版 | RulePacksTest、RulePackEvidenceTest、RuleUpgradeTest、SourceScopeBudgetTest；规则数量不等于实机覆盖 |
| 漏跳反馈、样本与 AI 草稿 | 用户发起采样并预览、保存、编辑或清除；草稿经正负样本审查后确认 | 越界或敏感节点、普通页同样命中、旧样本超期须拒绝或清理 | 本地采样/回放可用；联网能力以安装版权限为准 | MissedAdCaptureTest、SampleRetentionTest、LocalPrivacyTest、AiRuleDraftTest。未发送用户数据以验证外部 AI |
| 历史与会话统计 | 查看检测、动作、确认、无安全出口及按应用明细；关闭明细后清除 | 重试不能重复增加广告数；自然结束、晚回调与不确定结果不能算提前跳过 | 本地可用 | AdSessionsTest、StoreTest、RuleUpgradeTest；本机完全漏检的广告没有分母 |
| 连接守护 | 授权和服务连接分别展示，用户可开启守护、恢复或主动停止 | 锁屏/短暂断开、前台服务失败、用户关闭和通知受限时分开处理 | 本地可用 | AccessibilityRecoveryTest、AndroidCompatibilityTest、设备 keepalive。小米 / Redmi / POCO 真机长期存活未测 |
| 系统推广清理、恢复 | 根据设备预览条目、选择、执行、查看记录并逐项恢复 | 中断重试只处理剩余目标，通知/系统关键设置保留原值 | 本地可用 | PolicyTest、RouteTest、UiDriverTest、CleanRetryTest、StoreTest；厂商系统页面随 ROM 变化，仿真夹具不能替代真机 |
| 本机 DNS / VPN | 授权后建立本机 DNS 过滤，支持绕过应用和停止 | 网络切换、旧响应、VPN 撤销和保护域名均单独检查 | 不含 VPN 服务和网络权限 | DnsTest、DnsNetworkStateTest、AdFilterServiceTest 与安装包权限；未测所有运营商与 App 内置 DoH |
| 应用更新 | 完整版从更新通知进入校验、系统安装器与升级后配置恢复 | 下载中断、内容不符、证书/版本不符或无安装来源授权可恢复 | 手动安装正式签名 APK | ReleaseApkDownloadTest、ReleaseUpdatesTest、GithubReleaseFilesTest；公开线上下载与本地预置已完成下载分别取证 |
| 微信、QQ 原图 | 微信查看原图、微信勾选原图、QQ 查看原图、QQ 勾选原图四个开关独立。图片由用户决定发送 | 已勾选和普通图片页不应重复操作 | 本地可用 | MediaAssistTest 检查控件、位置及状态；社交应用当前版本的真实收发操作未验 |
| 最近任务卡片 | 设置“在最近任务中隐藏”，恢复后从最近任务进入 | 系统调用失败提示重新打开；应保留其余应用状态 | 本地可用 | 项目历史设备记录及设置实现；新版本与各厂商桌面的卡片隐藏 / 恢复另行核验 |
| 自愿赞赏 | 用户主动打开支持页面，可选择导出原始图片 | 拒绝导出仍可使用其它功能，图片内容与来源一致 | 本地可用 | ScreenTest.supportIsOptionalAndExportsOriginalImage；未进行支付交易 |
| 通知渠道 | 查看渠道并选择可处理的推广项，应用通知与渠道页面分开 | 保护关键通知、缺少渠道 ID 及低版本时保持原状态，可从历史恢复 | 本地可用 | StoreTest、UiDriverTest，源码渠道归属与系统版本保护；所有 ROM 的真实渠道面板未验 |
| 系统快捷设置磁贴 | 手动添加净屏规则磁贴，点击进入自定义规则 | Android 14 起通过 PendingIntent 打开；低版本走对应系统接口 | 本地可用 | RuleTile 和清单声明已核对；各厂商系统面板手动添加 / 跳转未逐一实测 |
| 版本与隐私说明 | 从使用说明查看当前版本、两版区别、权限及本机记录范围 | 用户仍能返回首页并清理本地明细；离线版无网络权限 | 两版显示各自版本信息 | LocalPrivacyTest、StoreTest、安装包清单验证；文案不能替代网络行为与设备检查 |

各包的版本、证据数量及适配状态见[应用适配质量矩阵](适配质量矩阵.json)。构建、系统版本、性能测量和已知缺口见[基线与设备记录](审计-基线与矩阵.md)。
