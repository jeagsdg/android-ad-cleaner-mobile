## 本版怎样使用

1. 首次使用时开启需要的广告处理场景，在无障碍设置选中净屏并返回。可到「无障碍授权 → 测试本机点击」核对真实连接。
2. 首页点「新增规则」，选择应用与广告类型，填写画面上实际出现的退出文字。弹窗还要填写同一弹窗的广告提示。也可以从应用详情、漏跳采集或脱敏样本中的控件起草。
3. 点「预览规则」检查范围和条件。选择「在目标应用试运行」后，可返回查看匹配结果。试运行只观察。取消「保存后启用此规则」可先存为暂停，之后在规则列表里启用、编辑或删除。
4. 还原备份时选「只添加新规则」可以保留已有条目与启停状态，选择替换全部会再次请求确认。使用完整版时，可在 DNS 过滤运行中修改应用绕过名单，已有连接可能需要重新连接。

漏跳反馈、样本填写和统计指标的具体入口见[使用与验收说明](3.0.0-验收口径.md)，历次版本变化见[更新日志](../README.md)。

## 安装后验收记录

- **升级通过。** Android 15 模拟器由未修改的 2.4.0 打开系统安装器，覆盖到顶部 SHA-256 对应的完整版。再次用顶部所列 APK 复验，系统安装器升级后回读的 SHA-256 与本地一致，开屏、弹窗、明细设置均保留。
- **DNS 运行中改策略通过。** Android 15 经过系统 VPN 许可后，12 项断言全部通过，包括本机 UDP 查询的拦截、放行、恢复拦截，以及按应用绕过并恢复。真实运营商网络与第三方应用自带 DoH 的效果尚待实测。
- **新增规则设备链路通过。** Android 15 的自定义弹窗在关闭后可能收到没有来源控件的系统点击事件。修复前退出回调已经出现，但计数未增加。修复后通过同一条完整路径的 62 项断言。系统归因、同包同窗、时序和事先核对过的唯一按钮同时满足时才接受这个回声；人工操作和模糊事件维持保守判定。

## 最终复验

新建规则的无来源点击回声修复已进入以上两份安装包。完整版 509 项、纯离线版 464 项全过，错误及跳过均为 0。双版 Lint 零错误，警告分别为 4 和 2。六组历史回放、22 棵重点应用页面均已复核。

Android 15 正式包覆盖安装和新增规则 62 项设备断言均通过；两版均验证本机点击和开屏。其他有完整安装包回读及三组设备行为证据的 API 为 24, 26, 27, 29, 30, 31, 33, 34, 36, 37。 Android 11 单独记录了测试框架连续强制停止应用后的绑定失败；逐场景冷启动结果与该失败分别保留。

|---|---|---:|---:|
| 普通开屏 | 8/8，8/8 | 1904 ms | 1533 ms |
