# 净屏 3.0.0 核心审计与实测

基线为正式 2.4.0（26），候选为 3.0.0（27）。项目采用一个 Android 应用模块、独立的测试广告应用、完整版与纯离线版两套源目录。最低 API 24，目标和编译 SDK 35。主应用依赖 Android 原生 API；Robolectric 与 JUnit 仅进测试。线上数据口径沿用关闭次数；新口径从升级后开始累计。

## 处理流程

1. 通过窗口状态、内容、窗口列表及用户交互事件确认前台。合并高频变化，以一次有界调度替代逐事件全树点击。
2. 优先应用指定规则，再使用已核实的 SDK 层、文字与布局。敏感操作、锁屏、移出目标窗口、相互冲突的目标会阻断执行。可信度采用证据条件与优先顺序，未训练数值概率模型。
3. 有真实倒计时才观察延迟出口。先识别来源，再选择独立按钮或该广告的唯一可用动作；短剧的原生翻页和普通点击分开。
4. 动作前重新获取窗口与目标，手势还要检查遮挡。接受动作、目标仍在、内容恢复、用户干预和结果不确定单独记录。
5. 「刚才没跳过」由用户发起，只保存必要的本地衍生信息。完全没有事件时无法在后台证明广告存在。

## 红果与重点应用

**红果**的现有公开证据是 7.1.9.32 的历史布局。四个快照分别用于检查可翻页广告、未解锁提示、正常播放或其他非目标状态。原树没有完整记录运行时动作能力；回放时补入 PAGE_DOWN 的结果是条件验证。新回归覆盖增加布局层、15 秒后无新事件解锁、慢速返回普通内容和用户先滚动。具备独立可点出口时可尝试提前退出。只在倒计时结束后出现翻页提示的样式只能在解锁后翻页。当前缺少本次反馈具体版本、真实 15 秒投放的连续动作与返回结果，无法给出真实提前退出率。[历史广告样本](https://i.gkd.li/i/32430183) · [样本适配说明](应用覆盖.md)

**移动云盘与迅雷**共同回放了 22 棵公开历史树。移动云盘包含 10.3.2 的轮播、悬浮、备份、系统提示；迅雷包含多个版本的开屏、下载详情页、搜索、会员和推广场景。旧版在目标 13627826、15048416、15048443 均为空，候选返回原树节点 5、32、16。原有悬浮广告 13627834 仍命中 36。搜索样本 16388942 里有可见广告关闭键 31 和包含“跳过”的搜索内容 22；前者可入弹窗候选，后者不入开屏候选。13228423 的上方广告带只读权限披露，下方广告有明确的关闭键。核对标识、披露结构和两块互不重叠的广告区域后，3.0.0 只选下方的第 19 节点；上方播放器关闭键、文件任务与购买页保持保护。24539634 不能只凭会员入口或推测的位置执行。这批历史树用于定位问题与回归，并非随机抽样或独立盲测。22 棵树中，9 棵标注有明确出口的正例，旧版选对 5 棵，本版选对 9 棵；6 棵已标注普通／敏感／无广告对照均未提出关闭目标，另外 7 棵按观察样本保留。静态匹配没有第三方点击回调。[每棵树的输入哈希、预期与实际节点](../artifacts/3.0.0-重点应用离线回放.json)。其余未提供名称及版本的几十个应用不补造名单。[全量矩阵](适配质量矩阵.json)

**补充样本最小集**：出问题的 App 版本、系统版本、两项功能开关；在「刚才没跳过」重现一次，记录刚出现、可点或解锁、动作后恢复三个阶段。另选同应用一张普通页面作反例。小米待机应记录锁屏前后真实绑定、异常系统事件、解锁恢复耗时，以及同一测试广告能否再次关闭。可单独分享经用户编辑的报告。

## 视觉辅助实验

对一张历史 B 站开屏按钮裁图建立模板，在另一版真实开屏及五个普通页／会员页上测试。脚本只在本地把画面缩至 360 像素宽，比较右下局部；每幅做 24 次，实际耗时见[原始结果](../artifacts/visual-exit-feasibility.json)。留出正样本的最高相关位置落在正确控件，分数 0.496；负样本也会返回其他位置。一个正样本不足以设通用阈值，更无法证明自绘广告可点击。本次只保留可按指定样本运行的离线实验，安装包不启用截屏、OCR 或视觉自动点击。API 30 可评估 takeScreenshot，API 34 可评估 takeScreenshotOfWindow；若后续扩展必须仅限用户授权目标、尊重安全窗口、取消和限频，并另行测手机功耗。[Android 无障碍服务 API](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)

另外用 Windows 自带中文离线 OCR 检查 6 张局部截图。对右上角能看见“跳过”的 4 张均识别出文字，2 张对照均未识别出；其中迅雷 15048354、24539634 的图像上确实有“跳过”，可读取的节点树没有对应的安全出口。文字识别无法证明遮挡、可点击状态或动作结果。这是工作站实验，耗时未包含手机截屏和解码，不能据此启用坐标点击或估算 Android 耗电。[六张逐样本结果](../artifacts/3.0.0-本地OCR评估.json)

## 指标口径

- 本机观测会话只覆盖出现过计时证据或安全候选的页面。按同一次观察去重，分别记发现、安全出口、动作提交、接受、确认关闭及耗时；误点、用户手动关闭、自然结束以用户指定结果另列。历史 2.4.0 的累计数字保留原义。
- 可操作广告成功率的分母为有安全出口的会话数；动作后验证率的分母为实际发起动作的会话数。测试集召回、处理覆盖与正常页误触需要人工标注独立分母。手机端计数不能用于推断完全漏检的广告。静态树只能给出命中结果。实际关闭率、提前退出率和误触率使用可观测的广告退出与负例动作回调。
- Android 系统无法可靠区分所有点击来源。已读控件消失若与自然结束或用户输入重合，不足以声称为自动提前退出。设备真实耗电、第三方实投 95% 目标、HyperOS 30 分钟至 24 小时存活均须按目标设备另测。

## 功能使用体验

新增规则的常用入口已放到首页、精选规则和应用漏跳反馈。普通用户先选应用、填写广告上的文字；包名、控件 ID 和页面名留在更多条件中。保存前预览作用范围，可试运行或只保存为暂停。新增的本地规则使用已有匹配器和无障碍执行链，手写规则与 AI 草稿分别沿用各自的校验。备份可只追加新规则；同一条规则不会因启停状态不同被再导入一次。系统开关预览可批量取消勾选后只选所需项目，守护页可查看真实观察到的断连次数与上次恢复耗时。[操作步骤](3.0.0-验收口径.md)


## 后续优先级

先收集上述三款应用最新投放的匿名正反样本，再做同机、同样式的前后对照；优先填补缺少稳定出口的样式、用真实用户可见动作检验延迟。只有在独立样本上证明收益并测过手机成本后，再扩大视觉或新模板的适用范围。
