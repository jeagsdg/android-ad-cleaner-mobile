# 规则工具与样本回放

**先重现一次，再决定如何修改。** 首页点「刚才没跳过」，选择应用和场景，重现前勾选「记录脱敏页面样本」。广告出现后切回净屏，从本机反馈报告打开「样本实验室」。选一个候选控件，改条件，点「重新匹配」：零个结果表示需要检查条件；多个表示还不够具体；一个只代表这次页面唯一命中，不代表实际关闭。

- 样本留在内存中五分钟。要以后再看，点「导出脱敏样本」。之后可在「自定义规则 → 打开页面样本」选择 JSON。桌面可下载并直接打开[本地样本审查器](../tools/样本审查.html)，查找 ID、类名或按钮文字，在位置图中核对。没有上传步骤。
- 样本包含应用、Activity、控件类名、资源 ID、可点击状态、位置和层级，只保留识别为广告或关闭动作的文字，其他正文隐去。样本缺少的文字不能当作实机上不存在；没有可读节点的画布不会变成一张截图。
- 「用这个条件起草规则」进入高级编辑器；弹窗还需要填写提示条件。先试运行，再保存。完整版也可使用自己的兼容 Chat Completions 的接口生成草稿，不会把树发送给模型。
- 可从系统快捷设置的磁贴编辑页添加「净屏规则」，直接进入规则工具。

## 订阅和表达式

精选规则内点「我的订阅」。完整版支持 HTTPS 订阅地址和手动检查更新；两版都可粘贴本地规则。预览列出将新增、移除、跳过的规则和与手写规则的重复项，确认后按来源保存，支持暂停、恢复和移除。失败时沿用原规则。官方签名规则仍在独立入口。

支持净屏规则备份，以及能完整翻译的 GKD 按应用开屏组。带未实现的活动范围、排除、时序、其他动作或全局规则不会去掉条件后执行。原生 JSON 可直接使用；对含扩展 JSON5 语法的文件，以实际解析预览为准。
高级编辑器中以 `gkd:` 开头，例如 `gkd:[vid="ad_panel"] > @[vid="skip"][clickable=true]`。支持类名、目标标记、父子、祖先和兄弟关系，以及 ID、文本、描述、长度、子项数、可见性和可点击状态的组合条件。不支持的表达式会指出出错位置。

## 实现范围

净屏参考 [GKD 固定版本](https://github.com/gkd-kit/gkd/tree/301e7e0a2aeb6ede954dcb93dbf53e56ae45a57d) 的选择器、订阅和快照工作流程，匹配器与审查器均为净屏独立实现。主项目与第三方规则来源分别列在 [NOTICE](../NOTICE.md)。本版未实现 GKD 的完整方法调用和坐标表达式语言、全局自动点击、远程操控、特权执行与跨设备桌面服务。官方 GKD 本身是否带 API Key 生规则入口，所核对版本未能证实。
