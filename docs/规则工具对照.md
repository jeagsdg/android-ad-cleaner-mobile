# 规则工具与样本回放

首页点「刚才没跳过」，选择应用和场景，重现前勾选「记录脱敏页面样本」。广告出现后切回净屏，从本机反馈报告打开「样本实验室」。选择控件并调整条件后，点「重新匹配」查看命中的位置和数量。

- 点「选择普通页作反例」，从文件或本机样本库选择同一应用的普通页面。两份样本完整、广告页唯一命中且普通页零命中时，本次对照通过。对照只在样本上匹配可读取的控件属性。
- 临时样本保留五分钟。可点「存入本机样本库」长期留在此设备，或点「导出脱敏样本」保存 JSON。在「自定义规则 → 打开页面样本」可打开净屏 JSON，或导入无输入控件的 GKD JSON、ZIP。导入时保留应用、Activity、控件属性和层级，正文脱敏，压缩包内的截图忽略。桌面可查看导出的净屏 JSON。 [本地样本审查器](../tools/样本审查.html)
- 点「用这个条件起草规则」进入高级编辑器。弹窗还需要填写提示条件。先试运行，再保存。完整版也可使用自己的兼容 Chat Completions 接口起草，模型收到的是这次填写的描述。
- 可从系统快捷设置的磁贴编辑页添加「净屏规则」，直接进入规则工具。

## 订阅和表达式

在「精选规则 → 我的订阅」可用文件导入或粘贴本地规则。完整版也可添加 HTTPS 地址，并为每个来源分别开启「每天检查这个来源」。打开净屏时会检查到期来源，发现新版后可查看变更并确认应用。

预览列出新增、移除、跳过和与手写规则重复的条目。应用后可暂停整个来源、管理单条规则、恢复上一版或移除来源，官方签名规则仍在独立入口。支持净屏规则备份和可完整转换的 GKD 开屏规则，包括明确限定普通应用的共享组、组合与排除条件、页面范围和部分时序选项。常用 JSON5 写法可导入，未能转换的条件会在预览显示。

在高级编辑器输入 `gkd:[vid="ad_panel"] > @[vid="skip"][clickable=true]` 可将广告容器中的可点跳过控件标为目标。支持类名、目标标记、父子、祖先和兄弟关系，以及 ID、文本、描述、长度、子项数、子节点顺序、深度、可见性和可点击状态的组合条件。

## 实现范围

净屏参考 [GKD 固定版本](https://github.com/gkd-kit/gkd/tree/301e7e0a2aeb6ede954dcb93dbf53e56ae45a57d) 的选择器、订阅和快照工作流程，匹配器与审查器均为净屏独立实现。主项目与第三方规则来源分别列在 [NOTICE](../NOTICE.md)。本版未实现 GKD 的完整方法调用和坐标表达式语言、全局自动点击、远程操控、特权执行与跨设备桌面服务。官方 GKD 本身是否带 API Key 生规则入口，所核对版本未能证实。
