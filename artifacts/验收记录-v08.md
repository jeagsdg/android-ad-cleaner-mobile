## 本轮修复与证据

- **荣耀应用市场开屏**。机主看到带秒数的「跳过」按钮，0.7 未关闭。已安装的 16.1.11.302 APK 移除了旧 `tv_operation_skip`，广告开屏布局使用 `btn_skip`。新增规则同时约束应用、主页面、10 秒时限、可点击按钮和跳过文字，保留其他安全校验。它是静态证据支持的修复，实际再次出现开屏时仍需核对关闭记录。
- **腾讯视频开屏**。用户确认漏跳发生在启动时。8.10.80.26895 的冷启动广告可显示「广告 | 已Wi-Fi预加载」，另外有独立热启动广告页。为两种可读原生模板内置专用规则。该按钮的代码注册的是触摸监听，净屏复查同一前台窗口和控件后才派发触控。绘制在画布上且没有可读按钮的变体仍待验证。新增酷狗音乐专用规则，以及按完整控件 ID 与可点击性匹配的华为广告 SDK 规则。
- **荣耀系统管家路径**。用户报告清理停在系统管家。当前 `com.hihonor.systemmanager` 15.0.0.347 的公开入口会转到 `com.hihonor.devicemanager` 15.0.0.316。根据两个 APK 的同签名与入口实现，新增明确的包切换和设置菜单 ID，最终只在原设置页匹配「应用推荐」。保留旧版路径，在已安装新版组件时跳过会误入跳板的旧菜单。当前的实际开关可读性和改动仍待该机验证。
- **清理到一半与结果可见性**。对单组检查设定 30 秒预算，识别重复滚动页面，遇到目标应用的协议页时记录本组并继续后续组。锁屏、用户切走及已尝试写入却无法确认结果时仍停止。启动时写入待执行清单，停止和失败后保留明细。结果按完成和未完成计数，两类都存在时才提供筛选。新增安全路径后规则目录为 75 组、113 条路径和 148 个开关定义，按手机实际安装和页面匹配处理。
- **OPPO / ColorOS**。区分尚未授权与开关打开后尚未连接。针对 Find X8 Pro 截图的权限管理路径提供入口，选择允许或拒绝过滤状态通知后均能继续检查应用详情。普通网络通知使用独立入口。标准 Android 授权由用户在系统设置中确认，是否恢复 ColorOS 灰显菜单仍待 OPPO 实机复验。[Android 受限制设置](https://support.google.com/android/answer/12623953?hl=zh-Hans) [无障碍服务生命周期](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)
- **微信赞赏**。从首页底部「支持作者 · 自愿赞赏」进入，使用本轮提供的 749 × 756 JPEG。包内图片和保存功能的输出与附件 SHA-256 一致。赞赏由用户自行在微信操作。

- 腾讯视频 8.10.80.26895 的原生模板通过触摸监听处理无资源 ID 的「跳过」文本控件，随后在 UI 任务中补设可点击属性。0.8 会拒绝尚未具备该属性的节点。新版在指定开屏窗口匹配该叶节点，冷启动还要求同窗口内的「广告」「广告 | 已Wi-Fi预加载」或「已Wi-Fi预加载」。检查控件位置及祖先操作语义，手势完成后才核对控件是否消失，取消时记录为未确认。另有自绘模板，跳过区域绘制在整屏 SurfaceView 内，未找到独立的可读跳过控件。
