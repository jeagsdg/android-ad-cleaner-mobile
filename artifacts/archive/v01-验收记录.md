## 已发现并修复

- Windows 中文构建路径导致测试进程 classpath 错误：构建脚本使用同一目录的临时 ASCII 联接。
- 测试环境冻结时钟导致等待不退出：执行器使用单调 `System.nanoTime()`。
- 用户切换前台或锁屏后不能继续下一条：终止整轮任务，保留已完成记录。
- 进程中途退出沿用上次结束状态：任务开始先写入未完整结束标记。
- AOSP 14 渠道标题不在顶部 22%：按实际 `entity_header_title` 与同容器 `entity_header_summary` 成对核验；不能匹配时仍拒绝操作。
- AOSP 通知 Switch 本身不可点击：向上寻找只包含此唯一开关且可点击的紧邻行容器，仍检查边界与数量。
- 英文系统的通知开关：加入明确中英文标签别名，合并为一个逻辑目标，避免重复计数。
- SDK 广告标识不应覆盖重要通知名称：额外保护支付、订单、聊天、天气预警等渠道。

## 未验证范围

小米、OPPO / 一加 / realme、vivo / iQOO、荣耀、魅族的专用系统/应用页面全部尚待对应厂商实机核验。未持有这些设备，模拟器和上游脚本记录不能替代这项检查。API 26–33、35 及更新版本未做本产品完整设备端闭环；Robolectric 的 API 28 / 34 渲染测试仅作自动化补充。

49 条规则是有来源、有限范围的尝试路径；系统改版、入口不导出、服务被系统停止或开关需要未知确认框时会跳过/停止并记录原因。没有实现网络过滤、通用视频广告拦截和所有第三方开屏跳过。

因此此交付为可安装的功能预览，适合小范围兼容性反馈；未达到「全品牌全部广告、无设置、保证不出问题」的正式商业发布标准。
